## Windows setup डाउनलोड
**[⬇ सहकार लक्ष्मी — Windows setup डाउनलोड करा](https://github.com/dubeyshrikant-boop/sahkar-mitra/raw/grihamitra-download/GrihaMitra_Setup.exe)** (सुमारे ३८ MB, Windows 10 / 11)

1. फाइल डाउनलोड करून चालवा → Desktop वर "Sahakar Lakshmi" icon (जुने "Griha Mitra" icon आपोआप जाते).
2. Windows ने "अनोळखी program" असा इशारा दिल्यास **More info → Run anyway**.
3. पहिल्यांदा उघडल्यावर «🎁 Demo मागवा» ने मागणी पाठवा (Boffin Meta मंजूर करताच परवाना आपोआप येतो), किंवा Boffin Meta कडून ई-मेलने आलेली परवाना फाइल `grihamitra_licence.json` द्या — किंवा ई-मेलमधील परवाना कोड (GM1.…) चिकटवा. स्वागत-पानावरील "संगणक कोड" परवान्यासाठी Boffin Meta ला कळवा.
